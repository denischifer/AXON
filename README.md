**AXON Engine**

**AXON** — это специализированный _движок пространственной математики_ для Minecraft (Fabric), предназначенный для оптимизации физических вычислений. Он заменяет стандартный перебор хитбоксов алгоритмами бинарного поиска в пространстве и SIMD-ориентированными вычислениями.

**_🚀 Основные технологии_**

1. **Voxel Bitmasking (Пропуск пустоты)**
Вместо дорогостоящих вызовов world.getBlockState(), AXON создает динамическую битовую карту плотности (Density Map) для каждого чанка.
* Чанк 16x16x16 разбивается на типы long. Один бит в лонге отвечает за наличие коллизии (0 — пусто, 1 — блок).
* При движении сущности выполняется один побитовый сдвиг и проверка. Если результат 0, физический движок мгновенно пропускает сотни циклов проверки геометрии.

2. **Flat-AABB (GC-Free Collision)**
Избавление от микро-фризов, вызванных созданием миллионов временных объектов Box при проверке столкновений в толпе мобов.
* Перевод расчетов на плоские массивы примитивов (12 переменных типа double вместо объектов).
* Данные упаковываются в регистры процессора и используют L1-кэш вместо медленной оперативной памяти.

3. **Spatial Hash Pruning**
Оптимизация расталкивания сущностей (Entity Pushing).
* Внедрение микро-сетки (Spatial Hash Grid). Сущности сравнивают свои хеш-ключи перед расчетом.
* Сложность алгоритма снижается с квадратичной до линейной
